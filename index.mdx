Wild Guess & Match is a Progressive Web App (PWA) designed for young children to learn about animals through sound, visuals, and hands-on play. It runs as a single-page React application backed by Netlify Functions and MongoDB, with four distinct game modes that adapt in difficulty as kids improve.

## Key Features

- **Progressive Web App**: Installable on mobile and desktop with offline support through `vite-plugin-pwa`.
- **Speech Synthesis**: Kid-friendly TTS announces animals, instructions, and rewards using the Web Speech API.
- **Adaptive Difficulty**: Guess mode increases options count and narrows choices by category as streaks grow. Match mode offers easy (3 pairs), medium (6 pairs), and hard (8 pairs).
- **Coin Economy**: Players earn coins through correct answers and matched pairs, spendable to unlock the Drawing Studio.
- **Parent Gate**: A math challenge prevents accidental profile setup by young children.
- **Optimistic UI**: Coin updates apply instantly on the client, then reconcile with the server after validated score submission.

## Tech Stack

| Layer | Technology |
| --- | --- |
| Frontend | React 19, TypeScript, Vite 8, Tailwind CSS 4 |
| Animation | framer-motion, canvas-confetti |
| Audio | Web Audio API (custom synthesis), Web Speech API |
| Backend | Netlify Functions (`@netlify/functions`) |
| Database | MongoDB via the Node.js driver |
| Testing | Vitest (unit), Playwright (E2E) |
| PWA | vite-plugin-pwa with auto-update |
